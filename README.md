# 震波之旅 · Quake Waves

选一场真实地震，看 **P 波与 S 波如何穿透地球内部**：
PREM 真实分层波速模型 + 射线追踪动画——S 波在外核消失、P 波穿核走时 21 分钟，
这些正是科学家推断"外核是液态"的关键证据。

"太空科普系列"第十弹。科普题材冷门但极适合可视化：几乎没人把这个做过动画。

## 运行

```bash
npm install --registry=https://registry.npmmirror.com
npm run dev     # → http://localhost:5182
npm test        # 地震学层回归测试（12 项，Node 直接跑）
```

## 你能看到什么

- **地球剖面**：PREM 分层（地壳/上地幔/过渡带/下地幔/D″/外核/内核）真实半径比例着色
- **P 波射线族**（红）：从震源向两侧对称展开——浅射线弯折于上地幔波导，
  深射线穿过外核（PKP），动画按**真实走时**推进（约 21 分钟压缩到 24 秒）
- **S 波射线族**（蓝）：走到核幔边界全部终止——外核液态、横波无法传播
- **真实地震**：右侧列表含 6 场历史大地震（东日本 9.1/苏门答腊 9.1/智利 9.5/汶川…）
  和 **USGS 实时目录**（M≥6 最近地震，网络不可达时仅显示历史列表）
- 播放/暂停、P 波/S 波/双波切换、时间读数（真实分钟）

## 物理内核（12/12 测试通过）

- PREM（Dziewonski & Anderson 1981）分层节点：真实 P/S 波速与密度
- 射线追踪：球对称介质中 **p = r·sin(i)/v 射线参数守恒**（斯内尔定律的球面形式），
  逐层积分走时；CMB 速度跳变处折射；外核段单独积分
- **P 波穿核走时 21.1 分钟**（真实地球物理值 ≈20 分钟）✓
- S 波 vs=0 无法穿外核 ✓；上地幔波导中浅射线弯回 ✓

## 诚实边界

- 单一射线参数 p 的几何近似，未做振幅/衰减/频散；PKP 出射角距偏小（回程镜像近似）
- 阴影带（103°–143°）的精确呈现需要完整的折走时曲线采样，v2 可加"台站接收闪烁"演示
